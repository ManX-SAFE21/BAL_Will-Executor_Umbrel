Paste one or more pre-signed raw Bitcoin transactions (hex-encoded). Each transaction must include an output paying at least the minimum fee to the server's address. The server will broadcast it when its locktime is reached.

How it works
1. Sign Create a Bitcoin transaction with a future locktime and sign it offline using your wallet.
2. Submit Paste the hex here. Include an output paying the fee to the server's address.
3. Wait This server watches every Bitcoin block. When the locktime is reached, it broadcasts your tx automatically.

Backup & Restore

Automatic Backups

This app creates an automatic backup of the database every Sunday at approximately 02:00 (server local time).

Backup files are named bal-YYYYMMDD.db and stored in the configured backup directory.

Up to 12 backups are retained (one per week for 12 weeks). The oldest backup is automatically removed when a new one is created.

Backup Storage Location
Path to store automatic backups. Leave empty for default (<data-dir>/backup). To use an external drive, enter its mount path (e.g. /mnt/external/backups).
Restore from Automatic Backup

Select a saved automatic backup to merge its transactions into the current database. Only new transactions are added — existing ones are preserved. The database is not replaced.

Changing the payment address or fee affects all future transactions submitted to this server. Transactions already stored are not affected.

If you change the address, new transactions will pay the fee to the new address. Old transactions already waiting will still pay to the old address.

Make sure the new address is correct. This action cannot be undone via the UI.
