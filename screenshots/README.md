# Screenshots for Umbrel App Store

Add PNG screenshots (recommended: 1280x800 or 1920x1200) to this directory.

Suggested screenshots:
1. `dashboard.png` — Main dashboard with server status, stats, and network selector
2. `settings.png` — Settings panel with payment address, fee, and description fields
3. `submit-tx.png` — Submit transaction panel with hex input
4. `search-tx.png` — Search transaction panel with result display
5. `backup.png` — Backup & Restore panel

Then update `umbrel-app.yml` → `gallery:` with the screenshot URLs.
